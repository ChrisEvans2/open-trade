# 模拟 runtime 部署验收边界（公开技术摘要）

本页保留验证方法和已知限制，不公开个人部署过程、服务状态、账户、通知回执或预测记录。需要自行完成[部署检查](../trading-agent/docs/deployment.md)，不能据此认为任何服务已经部署或可用。

## 验证方法

- 迁移前制作可验证备份，核对代码、迁移版本、配置、Profile和部署锁；只允许一个业务runtime。
- 共享核心、runtime单元、固定Hermes契约与隔离真实PostgreSQL分别验证；组件通过不能替代真实模型、通知送达或长窗口数据覆盖验收。
- 通知发送与回执不在数据库事务中；结果未知保留UNKNOWN，不盲目重发。规则见[通知说明](notification-audit-2026-11-04.md)。
- 代码回滚须兼容当前迁移版本。0012采集工作表可重建，正式预测、评分、成交和审计事实不得删除；需要向前修复。

## 仍需独立验证的限制

长窗口CVD要求完整的有效分钟覆盖；启动采集、循环成功或累计分钟数都不能代替逐窗口覆盖检查。资金费率需要连续时间覆盖，强平数据仅为公开样本。

PaperTransport基础测试未完整模拟手续费、滑点、资金费和延迟，不能用来宣称收益已验证。同一分钟触达目标与收盘失效的评分争议见[README](../README.md)，现有测试符合实现不等于规则正确。

断点续抓的技术变化与验证边界见[采集修复](cvd-checkpoint-repair-2026-11-04.md)。
