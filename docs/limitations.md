# 已知限制

- 当前PaperTransport不完整模拟手续费、滑点、资金费和成交延迟，不能将其结果视为真实净收益。
- 分钟聚合受分页、去重、源端修订、方向分类、预算和历史覆盖影响。总量一致不能证明买卖方向正确；不能按K线差额猜买卖分配。冷启动缺失或补抓不足须明确标记。
- 子模型输入为30根已收盘加1根未收盘快照；未收盘信号不冒充收盘确认。旧子报告可能早于父综合，不能当作刚采集行情。
- 同分钟目标与失效评分目前统一记AMBIGUOUS。触价失效与收盘确认失效的先后可能可判，需要同时审查规则及测试预期；本次导出没有修复该问题，不改历史评分。
- ETH/BTC相关性、beta和相对强弱是同源弱证据；公开强平为低重要性样本。指标缺失不以伪造数值补齐。
- 落库成功不保证复盘正文完整、预测有效或长期稳定。公开框架的测试结果不替代使用者的模型、隔离、部署和运行验收。
