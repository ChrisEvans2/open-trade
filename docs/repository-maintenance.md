# 公共仓库维护

公开仓库只保留框架代码、新写示例、合成夹具及通用说明；不接入个人交易历史或运维证据。后续同步使用明确文件清单，导出后复核差异和测试，避免将私人分支及祖先历史推入公开仓。

提交前检查工作树与暂存区，运行密钥扫描及个人标识检查；忽略规则不是历史清理工具。不要使用mirror或all把其他分支一并推送。新增示例的用户名、目录和数据须为通用值。

公开Git身份由仓库维护者选择；本地user配置与运行凭据相互独立。使用者的生产配置、认证、账户状态和备份始终留在仓库之外。

本次建立的是独立新仓库，未携带私人仓库的commit链；没有启动业务服务或修改原业务部署。只有经审核的公开文件才可进入首次提交。

维护环境已接入[自动同步](automatic-sync.md)：稳定窗口、三方合并、检查、独立提交和推送自动执行；异常保留现场并阻断该次发布。
