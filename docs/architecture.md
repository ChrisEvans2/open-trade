# 架构与数据约定

runtime负责行情冻结、任务身份、轮次、事实、确定性风控/执行与查询API。Hermes插件提供任务授权工具；Cube限制模型终端。主控Hermes与预测父Agent是不同角色，复用一个runtime。

每币种同一时刻一轮分析。确认事件按30秒固定窗口归并，需要更新的子周期并行执行，其余复用有效结果。最多4个子角色、2个共享沙箱名额；父和子分别受120秒执行与150秒阶段预算约束，整轮1200秒，新冻结输入年龄最多210秒。正常角色最多3次尝试；error恢复最多3次，分别退避60/180/600秒。次数和期限跨重启保存，不能靠重新排队无限恢复。

正式预测、输入、评分、分钟修订和审计为追加事实。任务写入在同一事务检查授权、租约、fence与期限；外部网络/进程不进入事务。资源清理不确定时保留名额隔离，不能把租约到期当作真实沙箱已销毁。

预测使用确认和临时证据，父综合使用子报告冻结来源。复盘分别保留原输入、事后重建参考和当前背景，历史不回填。知识由summary、案例content、procedure组织；期限学习须经过回放、影子及回滚规则。预测正确性、模拟账务和真实收益分别评价。

默认主动成交来源为逐笔分钟聚合，永久聚合与短期逐笔缓存分开。只有缓存允许过期删除；补抓追加新版本，旧预测引用不变。模型不负责抓取调度或改变预算。
