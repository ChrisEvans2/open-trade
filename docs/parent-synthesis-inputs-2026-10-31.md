# 父综合输入调整（2026-10-31）

按用户确认，父 Agent 综合四周期子报告，判断 1h 尺度的后续走势；父不再接收额外的一套自身 1h 行情。本次为本地实现，验证已完成，结果见下文；尚未部署或调用实际预测模型。

## 模型实际收到什么

| 对象 | 默认输入 | 必要时核查 |
|---|---|---|
| 1h、4h、6h、12h 子 Agent | 各自30根已收盘＋额外1根未收盘快照；80根已收盘计算的确认指标/结构；80＋1计算的26项PROVISIONAL指标 | 本任务授权证据和知识 |
| 父 Agent | 四周期有效子报告（结构、情景、目标、概率、解释、期限）、发布时间/有效期、各报告数据时点/临时指标状态、子报告采用的结构/边界、持仓、知识 | 按child_ref回读某份子报告原先冻结的30＋1和指标 |

父默认上下文没有model_bars、forming_candle、features、provisional_features或当前价格。父准备阶段不调用交易所时钟、合约信息、K线、外部指标、当前K线接口，也不运行自己的指标或结构计算。1h子报告仍是四周期综合的组成部分；查阅它的证据时，可看到它当时的30＋1，而不是另采一份父1h行情。

快照缺失仍明确MISSING，不补造第31根。四个子报告可能在不同时间生成；父看到各自发布时间、最后收盘时点、快照时点、临时项数量及有效期，不能把复用的旧子报告视为刚更新的行情。临时指标的具体判断由子报告提供，数值可通过证据展开核查。默认不批量重复输入四套原始行情。

## 综合判断与结构验证

父仍生成自己的方向概率、条件情景、目标、失效条件和交易意图，说明主要依据哪个周期、受到哪些条件限制，解释延续、回调、冲突与未知。提示词要求考虑全部有效子报告，不能机械平均或照抄1h。

- 结构候选仅来自有效子报告实际采用的程序候选，标记来源周期；父没有自己的额外1h候选计算。
- 父情景的边界和容差必须匹配某份冻结子报告的边界证据，程序校验原始价格线、斜率和容差。父可以组合不同周期的边界，但不能编造新边界或放宽容差；结构不明确时可选UNKNOWN。
- 父期限仍以1h为单位，使用既有1h同结构/阶段的期限规则（与1h子报告共享规则组），初始规则仍为4根即4小时。不把4h子报告的4根直接解释成父的16小时。
- 既有缺周期标记保留；原生轮次协调器仍按原有规则等待需要更新的子结果。没有任何有效子报告则拒绝生成父输入。

父发布时仍重新检查子预测有效性、版本、持仓和任务权限；冻结后若子结果更新，旧父提交被拒绝。历史事实不改写。

## 按需读取与复盘

research_context增加可选child_ref，只有父任务可读取本次冻结引用内的子证据。服务校验同引擎、同币种、同周期、TIMEFRAME角色和原输入hash；任意ID、跨范围、多参数、子任务越权及失效租约不能读取。读取固定来源，不跟随最新head变化。

新父输入标为CHILD_SYNTHESIS，保留子预测、输入ID/hash和边界来源。复盘遇到这种输入时，明确它没有独立父K线，不为父额外重建1h快照。旧父30＋1事实和既有回放路径保留；复盘的四周期320根当前背景输入保持原有用途。

## 程序取值的配套决定

以下为本次实现必须处理的程序依赖，不是新增模型行情输入：

1. 原执行风控依赖父指标中的ATR。本次改为保存有效1h子报告的已确认atr_pct及来源输入/时点，供确定性执行使用，父模型上下文不提供此字段。缺少该来源时拒绝订单准备，不用4h ATR冒充1h ATR、不放宽风险限制。该ATR随子报告冻结，可能早于父综合时点；执行仍使用原有当前分钟行情和有效性检查。没有新增独立ATR刷新任务。
2. 已发布预测的既有数据契约要求reference_price。程序沿用最新发布子报告的原参考价并记录来源（同时间按周期名称稳定选择），仅用于保留事实契约；不将它标为父当前价或传给父模型，也不替代执行的市场报价。
3. 未新增表或迁移。父输入schema_version=4、input_kind=CHILD_SYNTHESIS；模型内容契约保持4，避免无关工具协议迁移。历史输入按原契约读取。
4. 保留旧父独立1h输入方案为[后续可选TODO](TODO.md)，没有自动恢复入口。
