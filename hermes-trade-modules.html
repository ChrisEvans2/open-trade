行情预测

AI 判断 ＋ 程序校验

子 Agent 分周期分析；父 Agent 负责综合决策。模型只提出意图，订单由后续程序处理。

谁操作
Hermes 运行四个周期角色和父综合角色，Runtime 安排任务。
输入
冻结行情、量化特征、结构候选、有效子预测、知识与持仓上下文。
输出
结构、概率、触发条件、目标区间、失效条件与期限；父综合发布交易意图。
权限
通过授权研究工具读数据、提交报告；不能调用订单接口或提高风险上限。

OKX API key 放在哪一环？

公共行情抓取客户端不需要 key。账户、持仓和订单读取走私有接口；交易执行使用相应权限。凭证由程序配置，分析模型不需要持有交易密钥。

AI 决策与程序执行怎样分工？

AI 判断方向与情景；程序验证预测条件、风险和订单状态。父预测失效或转向可提出平仓；单纯预测到期继续现有持仓保护。

学习能改动什么？

复盘提出知识更新。期限调整由程序经过历史回放、后续影子验证和回滚规则控制；不改写已发布预测、历史评分或策略源码。
